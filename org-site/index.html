Alfred

Consent-first messaging

No message is delivered until the recipient has explicitly allowed the sender. Alfred is feminist-informed software: consent, agency, and clear boundaries are built into the architecture.

Try the app Source on GitHub

About

Alfred is open-source messaging delivered as a Flutter web app (installable as a PWA). Users are identified by username; conversations are address-based.

Each account controls who may reach them through a personal allow list. Senders who are not allowed are not delivered to — there is no silent inbox from unknown parties.

Get started

git clone https://github.com/alfred-im/alfred-im.git
cd alfred-im/client
flutter pub get
flutter run -d web-server --web-port=8080 --web-hostname=0.0.0.0

Open http://localhost:8080/ — see the repository README for local Supabase setup.
